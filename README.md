## Entry

**Forgettable**

Exactly one word — the word my ex would use to describe me, and nothing else. It is self-deprecating and painfully honest: not unforgettable, not legendary, just forgettable. It lands instantly, needs no explanation, and stings because it is true.

## Run

```sh
node main.ts
```

The program writes exactly one word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no dependencies, no generator — it only writes the single word above.
